# ASPRS Certification Manual (2019)

The **ASPRS Certification Manual (2019)**, revision dated July 12, 2019, is an earlier edition of the ASPRS Certification and Recertification Guidelines. It is preserved alongside the current edition because it contains material the current edition dropped: a dedicated Geospatial Intern Program section, Geospatial Intern rows in the fee table (initial application $200 for members and $250 for non-members, final application $100 and $200), the program history recording that provisional certification was approved in May 2006 and later re-designated the Geospatial Intern Program, and "Geospatial Intern (ASPRS)" in the list of designations certified individuals may use.

For intern pathway facts, this document and the archived application page preserved as [ASPRS Intern Application Page](/sources/asprs-intern-application-page.md) are the best available written sources, with the caveat that both predate the current program administration and may not reflect current fees or procedures.

## Original Source

The original PDF is preserved in this folder as `asprs-certification-manual-2019.pdf`. The live URL (https://www.asprs.org/wp-content/uploads/2019/07/ASPRS_Certification_Manual_2019-07-12.pdf) now returns an error page after an ASPRS site migration, so the PDF was retrieved 2026-07-10 from the Internet Archive snapshot at http://web.archive.org/web/20240104160522/https://www.asprs.org/wp-content/uploads/2019/07/ASPRS_Certification_Manual_2019-07-12.pdf.
