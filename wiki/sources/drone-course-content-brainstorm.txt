## Foundations: Defining Drones and UAVs

## Understanding Light and Sensors

### How Digital Cameras Work

Understanding light and the electromagnetic spectrum is crucial for advanced drone applications. Digital sensors work by dividing a surface into tiny cells. When light hits these cells, it's converted into an electrical signal, which is then translated into a brightness value. Millions of these measurements arranged in a grid create an image.

Color images are created by filtering the light that hits the sensors—allowing only red light to reach certain cells, only green to others—then using mosaicing algorithms to produce a color image. It's important to understand that the raw images cameras produce are flatter and more subtle than what we're used to seeing. Digital tools transform these values to exaggerate and enhance them into familiar-looking images.

### RAW vs JPEG: Data Preservation

RAW images contain the unprocessed values from the sensor, while JPEG is a lossy format that discards information to reduce file size. For most casual photography, JPEG is appropriate—you don't need raw values just to see the image. However, for professional drone work, RAW is essential.

If you're selling images or need maximum editing latitude, shoot in RAW. You can always convert to JPEG later, but you can never "unbake" a JPEG. For applications using images as data sources for observation and measurement—such as calculating NDVI (Normalized Difference Vegetation Index) to measure photosynthetic activity—you absolutely need RAW values, as they're as close to the truth as possible.

Professional multispectral analytic images will look flat and boring initially. Understanding how to appropriately stretch these values is critical.

### Bit Depth and Image Precision

Bit depth represents the number of potential values in an image—typically 256 values (8-bit) for standard images, but multispectral images can have around 32,000 or more possible values. This higher bit depth provides much more precision and information, though it requires more storage space.

Bit depth can be understood through a ruler analogy: a coarse ruler might only measure in quarter-foot intervals, while a precise ruler measures in fractions of an inch. More markings give you more accuracy but add weight. Similarly, higher bit depth means more shades of gray, more ability to discern measurements, and more storage required on disk.

## The Electromagnetic Spectrum in Drone Applications

The visible color spectrum represents a very narrow band of the continuous electromagnetic spectrum. Cameras can observe beyond visible light, but this requires engineering decisions—special glass filters that control which wavelengths reach the photosensitive sensor while blocking others.

### Beyond Visible Light: Infrared and NDVI

Beyond visible light, infrared is particularly useful because it can distinguish between photosynthetic and non-photosynthetic materials. The "red edge" is valuable in agricultural contexts, though agricultural plants are "unnaturally photosynthetic" which can complicate analysis and reduce ability to discern variation in photosynthetic capacity.

NDVI represents a major branch of drone applications in agriculture, but greenness measurement has broader applications beyond farming. While ultraviolet light has limited drone applications, it has scientific uses—such as studying flower colors and snake patterns visible in UV light—and would be worth researching further for potential course content.

## Drones as Payload Platforms

A drone is fundamentally an aircraft that doesn't require a human pilot physically onboard. While hobbyists fly drones for their own benefit (FPV, toys), professional drones are built to carry payloads that perform useful functions.

### Civilian vs Military Applications

The earliest drones were military weapons platforms—small planes carrying munitions to strike enemies from a distance without risking human life. This technology has evolved significantly, with Ukraine now considered world experts in drone warfare. Fortunately, drones have transitioned to civilian applications with entirely different purposes.

### Sensor Types: Passive and Active

The most common civilian payload is a camera, which is a passive sensor that measures reflected light. The overwhelming majority of drone measurements are simple color photographs, though these can be used analytically.

Other sensor types include:
- **LiDAR**: An active sensor that produces its own signal and measures the reflection
- **Sonar** and **ground-penetrating radar**: For measuring underground water
- **Environmental sensors**: Temperature, wind, and pressure sensors

In this context, weather balloons qualify as UAVs—platforms designed to carry measurement payloads and report data.

## Aerial Platforms in Context

Drones exist within a continuum of aerial platforms: helicopters, airplanes, satellites, weather balloons, and kites. All carry equipment into the sky to make measurements, each with distinct pros and cons.

For large-scale landscape monitoring at state or continent level, drones are impractical—it would take so long the seasons would change before completion. Satellites solve this by placing similar cameras much further away, trading resolution for coverage. Commercially available satellite imagery provides roughly 10-foot resolution—enough to measure average light reflection from a plot of land, which becomes powerful when repeated across vast areas over time.
