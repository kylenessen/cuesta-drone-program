# Cuesta UAS Technology Program

This repository contains curriculum development, program planning, and supporting research for Cuesta College's UAS Technology Program.

## Current program sources

The [College Council packet submitted October 27, 2026](docs/program-approval/2026-10-27-college-council-packet.docx) is one of the most authoritative documents for the current program. Start with this packet for program scope, certificate names and requirements, course sequencing, FTES projections, and the proposed budget. The [submission record](docs/program-approval/README.md) explains its status and provenance. Submission is recorded here. Final College Council approval has not yet been recorded.

The [NOI source guide](curriculum-content/README.md) links the five course Notices of Intent, their saved content, and their CurrIQunet records. Use these sources for the course details behind the packet, including the AERO 151 lab and contact hours. The guide distinguishes the saved draft record from subsequent curriculum approval.

The [2026–2027 Cuesta catalog reference](sources/cuesta-catalog-2026-2027/README.md) documents existing support courses. The packet's GIS courses use GEOL 230, GEOL 231, and GEOL 234, which were checked against the current catalog on October 27, 2026.

## Working with this repository

Keep the submitted packet unchanged as the record of what was sent. Record later approved changes in a new dated document and update the source guides. Earlier certificate proposals and course outlines preserve the planning history, but their placeholder numbers and program structures may have been superseded. Prefer the submitted packet and the NOI records when establishing the current program, and reconcile any conflict explicitly against the latest approved curriculum record.

Program approval records live in [docs/program-approval](docs/program-approval/README.md). Course development and NOI sources live in [curriculum-content](curriculum-content/README.md). The [wiki](wiki/index.md) contains teaching resources and research. Communications, meeting notes, purchasing plans, and reference material retain their existing folders.

Intermediate College Council packet copies and temporary review artifacts were removed after submission. Git history preserves the committed review rounds.
