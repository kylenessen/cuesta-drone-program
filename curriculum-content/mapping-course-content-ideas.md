# Advanced Mapping and Photogrammetry - Content Ideas

This document captures content ideas for the advanced mapping course as they come up. Curriculum is still in development. AERO 100 serves as a prerequisite.

## Course Philosophy

The goal is to get students from zero to one. I am not trying to impart everything I know. I want to give them a foundation they can grow from.

## RTK and Positioning

### Why RTK Matters
- If I was doing this for myself, 100 percent, every time I would spend the money on RTK
- Essential for the kind of accuracy that professional mapping requires
- A huge part of the curriculum to discuss

### Base Station Setup
- Tripod placement
- NTRIP vs local base corrections
- Coordinate systems and datums

### Rover Operation
- Survey pole technique
- Bipod for stability
- Taking points efficiently

### Equipment Choices
- Emlid over Trimble (better value, appropriate for starting from zero)
- Skills transfer between platforms
- Part of being a good drone pilot is being adaptable to different tools

## Ground Control Points

This is fundamental curriculum and a reasonable ask for any serious mapping program.

### GCP Placement Strategy
- Distribution across the site
- Edge and center coverage
- Dealing with terrain variation

### Marking Techniques
- Target types and visibility
- Permanent vs temporary markers

## Flight Planning

### Terrain Following
- Critical in our neck of the woods (SLO area has variable topography)
- How terrain following algorithms work
- When to use it vs constant altitude

### Overlap and Coverage
- Why overlap matters for photogrammetry
- Standard overlap percentages
- Tradeoffs between coverage and flight time

### Mission Planning Workflows
- Site assessment
- Airspace considerations
- Weather windows

## Photogrammetry Processing

### Getting from Zero to One
- Basic processing workflow
- What the software is actually doing
- Interpreting results

### Going Deeper (For Interested Students)
- Ground control point optimization
- Dense cloud settings
- Mesh generation options
- Orthomosaic quality assessment

### Software Approaches
- Cloud-based (DroneDeploy): Simple path to producing maps
- Desktop (Metashape): More control, software you can grow into, own the license
- Open source (OpenDroneMap): Worth exploring

## Data Management

### Minimum Viable Folder Structure
- Every organization will have its own workflow
- Teach a baseline that works
- Project organization principles

### What to Keep, What to Archive
- Raw imagery
- Processed outputs
- Project files
