### Proposal Rationale

Drone mapping and photogrammetry represent one of the fastest-growing segments of commercial UAS employment. Industries including surveying, construction, environmental monitoring, and civil engineering increasingly rely on drone-collected aerial data processed into orthomosaics, elevation models, and volumetric calculations. This course builds on the foundational skills taught in AERO 100 to prepare students for professional mapping positions requiring RTK positioning, ground control methodology, photogrammetry processing, and deliverable production. San Luis Obispo County's active construction, agriculture, and environmental sectors provide direct employment pathways for graduates with these skills.

### Catalog Description

Prepares students to plan and execute professional drone mapping operations, from mission planning through deliverable production. Covers RTK positioning and ground control point methodology for survey-grade accuracy, photogrammetry processing using industry-standard software, and data management workflows. Students produce orthomosaics, digital elevation models, and volumetric calculations meeting professional specifications. Emphasizes practical skills applicable to surveying, construction, environmental monitoring, and civil engineering contexts.

## Topics and Scope

### Detailed Topical Outline

1. **Topic:** Positioning Fundamentals
   - GPS, GNSS, and RTK positioning concepts
   - Accuracy levels achievable with different positioning methods
   - Base station setup and operation
   - NTRIP network corrections and configuration
   - Coordinate systems and datums
   - **Objectives:** (Obj 1)

2. **Topic:** Ground Control Points
   - GCP theory and effect on photogrammetric accuracy
   - Network design for different project sizes and terrain
   - Target selection, deployment, and visibility considerations
   - Survey procedures and quality checks
   - Data export for processing software
   - **Objectives:** (Obj 2)

3. **Topic:** Flight Planning and Execution
   - Ground sample distance and altitude relationships
   - Front lap and side lap overlap requirements
   - Terrain-following algorithms and DEM sources
   - Mission planning in DJI Pilot 2 and third-party applications
   - Weather and lighting conditions for photogrammetry
   - Field execution, pre-flight checklists, and mission monitoring
   - **Objectives:** (Obj 3)

4. **Topic:** Photogrammetry Processing
   - Structure from motion principles
   - Processing workflow: alignment, dense cloud, mesh, orthomosaic
   - Cloud-based processing (DroneDeploy)
   - Desktop processing (Agisoft Metashape)
   - Open source alternatives (OpenDroneMap/WebODM)
   - GCP import, marking, and optimization
   - **Objectives:** (Obj 4, 5)

5. **Topic:** Elevation Products and Analysis
   - Digital Surface Model versus Digital Terrain Model
   - Contour generation and interval selection
   - Volumetric analysis: cut/fill and stockpile measurement
   - Deliverable formats (GeoTIFF, LAS, shapefiles)
   - **Objectives:** (Obj 5, 6)

6. **Topic:** Data Management and Professional Practice
   - Project folder structure and naming conventions
   - Flight logs and processing parameter documentation
   - Archival practices and storage requirements
   - Equipment maintenance schedules
   - Client delivery documentation
   - **Objectives:** (Obj 6)

## Assignments

1. **Assignment Type:** Assignment
   Design a GCP network for a given project area, justify placement decisions based on terrain and accuracy requirements, deploy targets, and survey positions with RTK equipment.
   - **Course Objective:** (Obj 1, 2)

2. **Assignment Type:** Assignment
   Plan and execute a complete mapping mission including flight parameter calculation, terrain-following configuration, and post-flight image quality verification.
   - **Course Objective:** (Obj 3)

3. **Assignment Type:** Assignment
   Process drone imagery through full photogrammetry workflow in both cloud and desktop software, compare outputs, and evaluate quality through error analysis.
   - **Course Objective:** (Obj 4, 5)

4. **Assignment Type:** Assignment (Capstone)
   Complete an independent mapping project including site assessment, GCP survey, mission execution, processing, deliverable production, and professional documentation package.
   - **Course Objective:** (Obj 1, 2, 3, 4, 5, 6)

**Critical Thinking Assignments (minimum 2 examples):**

- Given project specifications and accuracy requirements, calculate appropriate flight parameters and design a GCP network, justifying each decision based on terrain, budget, and deliverable needs. (Obj 2, 3, 5)
- Evaluate photogrammetric outputs from multiple processing approaches, identify sources of error, and recommend workflow improvements for a client project. (Obj 4, 5, 6)

**Independent Work (minimum 2 examples):**

- Execute a complete mapping mission independently, from GCP deployment through deliverable export, documenting all decisions and procedures. (Obj 1, 2, 3, 4, 5, 6)
- Process a provided dataset using desktop photogrammetry software, producing orthomosaic, DEM, and contour deliverables meeting specified accuracy and format requirements. (Obj 4, 5, 6)
